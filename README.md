# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview
This HR Analytics Dashboard is built using Microsoft Power BI to help organizations analyze employee data and gain insights into workforce performance, employee attrition, demographics, and overall HR metrics.

---

## 🚀 Features

- Total Employees
- Employee Attrition Analysis
- Attrition Rate
- Active Employees
- Average Age
- Department-wise Analysis
- Gender Distribution
- Job Role Analysis
- Education Field Analysis
- Age Group Analysis
- Interactive Filters (Department, Gender, Education, Job Role)

---

## 🛠 Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV

---

## 📂 Dataset

The dashboard uses HR employee data containing:

- Employee ID
- Age
- Gender
- Department
- Job Role
- Education
- Salary
- Years at Company
- Attrition
- Marital Status
